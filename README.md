# encoaca

`encoaca` is a Rust-based application featuring integration with the Nostr protocol.

## Project Structure

The codebase is organized into the following modules:

*   **`main.rs`**: The entry point of the application.
*   **`nostr.rs`**: Contains implementation logic for interacting with the Nostr protocol.
*   **`helper.rs`**: Provides utility functions and helper methods used across the application.
*   **`tests.rs`**: Contains the test suite for validating application functionality.

## Prerequisites

To build and run this project, you must have the Rust toolchain installed.

* Install Rust and Cargo via [rustup](https://rustup.rs/):
  ```sh
  curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
  ```

## Getting Started

### Clone the Repository

```sh
git clone https://github.com/mirenox14/encoaca.git
cd encoaca
```

### Build

To compile the project and its dependencies:

```sh
cargo build
```

For a release build:

```sh
cargo build --release
```

### Run

To execute the application:

```sh
cargo run
```

## Running Tests

Execute the unit and integration tests defined in `tests.rs`:

```sh
cargo test
```
